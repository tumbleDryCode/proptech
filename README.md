# proptech
Scripted for small to medium size real estate agencies.

<br>

# Requirements
    PHP >= 5;
    MySQL >= 5.7;

# Installation
    Upload project to your web folder.
    Import the dev/db.sql database file to your databse.
    Modify include/config.php file with database settings.
